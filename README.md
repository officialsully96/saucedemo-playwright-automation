# SauceDemo E2E Automation Suite 

This is a professional-grade test automation framework built with **Playwright** and **TypeScript**. 

## Architecture: Page Object Model (POM)
I utilized the Page Object Model to ensure the tests are:
- **Maintainable:** Changes to the UI only require updates in one place.
- **Readable:** Tests are written in clear, descriptive steps.
- **Scalable:** New pages can be added easily as the app grows.

## 🛠️ Tech Stack
- **Framework:** Playwright
- **Language:** TypeScript
- **Version Control:** Git & GitHub
- **Pattern:** Page Object Model

## 📸 Features
- Automatic unique-timestamped screenshots for every test run.
- Custom locators using `data-test` attributes for stability.
